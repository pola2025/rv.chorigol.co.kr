# 📄 Pages 폴더 가이드

## 📁 페이지 컴포넌트 구조 및 용도

### 📊 통계 페이지
- **Statistics.jsx**            → 메인 통계 페이지
  - 전체 운영 통계 대시보드로 매출, 예약률, 고객 분석 등 종합 정보 제공
  
- **MonthlyStatsDemo.jsx**      → 월별 통계 데모 페이지
  - 월간 실적 데이터 시각화 및 전월 대비 성장률 분석 화면
  
- **StatisticsCardDemo.jsx**    → 통계 카드 컴포넌트 데모
  - 대시보드용 통계 카드 UI 컴포넌트 테스트 및 프리뷰 페이지

## 🗺️ 라우팅 구조

### 현재 구현된 라우트
```javascript
/statistics          → 통계 메인 페이지
/stats/monthly       → 월별 통계 상세
/stats/demo          → 통계 컴포넌트 데모
```

## 📋 페이지 구성 패턴

### 페이지 컴포넌트 구조
1. **레이아웃 래퍼**: 공통 레이아웃 컴포넌트로 감싸기
2. **데이터 페칭**: useEffect에서 초기 데이터 로드
3. **상태 관리**: 페이지별 로컬 상태 또는 전역 스토어 연결
4. **컴포넌트 조합**: 작은 컴포넌트들을 조합하여 페이지 구성
5. **에러 바운더리**: 페이지 레벨 에러 처리

## 🎯 추가 필요 페이지 (권장)

```javascript
// 예약 관리
/reservations        → 예약 목록 및 관리
/reservations/new    → 새 예약 생성
/reservations/:id    → 예약 상세 정보

// 객실 관리  
/rooms              → 객실 목록 및 관리
/rooms/:id          → 객실 상세 정보

// 고객 관리
/customers          → 고객 목록
/customers/:id      → 고객 상세 및 예약 이력

// 설정
/settings           → 시스템 설정
/settings/pricing   → 가격 정책 설정
/settings/notifications → 알림 설정

// 보고서
/reports            → 보고서 목록
/reports/revenue    → 수익 보고서
/reports/occupancy  → 객실 가동률 보고서
```

## 💡 페이지 개발 가이드라인

1. **네이밍**: 페이지 용도를 명확히 나타내는 이름 사용
2. **코드 분할**: React.lazy()를 사용한 동적 임포트
3. **SEO 최적화**: 페이지별 메타 태그 설정
4. **접근 제어**: 페이지별 권한 체크 구현
5. **로딩 상태**: 스켈레톤 UI 또는 로딩 스피너 표시
6. **에러 처리**: 사용자 친화적인 에러 메시지 제공

## 🔒 인증 및 권한

- 모든 페이지는 로그인 체크 필요
- 역할 기반 접근 제어 (RBAC) 적용
- 비인증 사용자는 로그인 페이지로 리다이렉트
