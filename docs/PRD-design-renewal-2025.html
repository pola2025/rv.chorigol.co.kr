6 React Bits 활용 계획

React Bits는 110+ 애니메이션 컴포넌트를 제공하는 오픈소스 라이브러리입니다.

컴포넌트 적용 위치 효과 데모 우선순위
Aurora Background 로그인 화면 배경 몰입감 있는 첫 인상 데모 보기 → High
Spotlight Card 통계 카드 마우스 따라다니는 하이라이트 데모 보기 → Medium
Text Animation (Blur) 대시보드 타이틀 텍스트 등장 애니메이션 데모 보기 → Low
Tilted Card 예약 카드 hover 3D 기울기 효과 데모 보기 → Medium
Animated Counter 통계 숫자 카운트업 애니메이션 데모 보기 → Medium
설치 완료: react-bits, gsap, framer-motion, @react-spring/web

7 화면별 개선 계획

7.1 로그인 화면

P1 - High

현재

  • • 단순 그라디언트 배경 (녹색)
  • • 기본 카드 스타일
  • • 비밀번호만 입력

개선

  • • Aurora 배경 애니메이션 적용
  • • Glassmorphism 로그인 카드
  • • 입력 필드 focus 애니메이션
  • • 로고 애니메이션 추가

7.2 대시보드 헤더 & 네비게이션

P1 - High

현재

  • • 흰색 배경 단순 헤더
  • • 기본 탭 네비게이션
  • • 단순 아바타

개선

  • • Glass 효과 헤더 (스크롤 시 blur)
  • • 애니메이션 탭 인디케이터
  • • 다크 모드 토글 추가
  • • 호버 마이크로 인터랙션

7.3 예약 캘린더

P2 - Medium

현재

  • • FullCalendar 기본 스타일
  • • 보라색 헤더 그라디언트
  • • 기본 예약 칩

개선

  • • 그린 계열 헤더로 변경
  • • 날짜 셀 hover 효과 강화
  • • 예약 칩 디자인 개선
  • • 오늘 날짜 강조 스타일
⚠️ 캘린더 로직은 변경하지 않음 - 스타일만 수정

7.4 예약 상세 패널

P2 - Medium

현재

  • • 파란색 헤더
  • • 기본 카드 리스트

개선

  • • Glassmorphism 패널
  • • 예약 카드 Tilted 효과
  • • 슬라이드 인 애니메이션

7.5 모달 / 팝업

P2 - Medium

현재

  • • 기본 오버레이
  • • 단순 fade 애니메이션

개선

  • • blur 배경 오버레이
  • • Glass 모달 컨테이너
  • • scale + fade 애니메이션

P3 - Low

  • • 카드 스타일 통일
  • • 버튼 스타일 통일
  • • 입력 필드 스타일 통일
  • • 테이블 스타일 개선

8 위험 요소 및 대응 NEW

⚠️

기술적 위험

High
위험 요소 React Bits 라이브러리 호환성 이슈
영향도 애니메이션 미작동, 빌드 실패
대응 방안 순수 CSS/Framer Motion으로 대체 구현 준비
⏱️

성능 위험

Medium
위험 요소 과도한 애니메이션으로 성능 저하
영향도 모바일 기기에서 버벅임, 배터리 소모
대응 방안 prefers-reduced-motion 존중, 필수 애니메이션만 적용
🔄

롤백 계획

Low
전략 theme-2025.css를 별도 파일로 관리
롤백 방법 CSS import 제거로 즉시 원복 가능
롤백 시간 5분 이내
🌐

브라우저 호환성

Low
위험 요소 backdrop-filter 미지원 브라우저
영향 범위 IE, 구형 Safari (사용률 <2%)
대응 방안 @supports 쿼리로 fallback 스타일 제공
