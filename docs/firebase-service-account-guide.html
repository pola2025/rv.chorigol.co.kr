Firebase 서비스 계정 키 획득 가이드

Firestore 데이터 직접 조회를 위한 인증 키 설정

진행 체크리스트

1

Firebase Console 접속

아래 링크를 클릭하여 Firebase Console에 접속합니다.

Firebase Console 열기 (choho-pension)
TIP: Google 계정으로 로그인이 필요합니다.
2

서비스 계정 탭 확인

위 링크를 통해 접속하면 자동으로 서비스 계정 탭으로 이동합니다.

경로:

⚙️ 프로젝트 설정 → 서비스 계정 → Firebase Admin SDK
3

새 비공개 키 생성

  1. a "새 비공개 키 생성" 버튼을 클릭합니다.
  2. b 확인 팝업에서 "키 생성"을 클릭합니다.
  3. c JSON 파일이 자동으로 다운로드됩니다.
⚠️ 주의: 이 키는 다시 다운로드할 수 없습니다. 안전한 곳에 보관하세요.
4

파일 저장

다운로드된 JSON 파일을 아래 경로로 이동합니다.

choho-admin/
└── functions/
    └── serviceAccountKey.json  ← 여기에 저장

🔒 보안 필수 확인

.gitignore에 다음 내용이 있는지 확인하세요:

serviceAccountKey.json
**/serviceAccountKey.json

✅ 설정 완료!

서비스 계정 키가 준비되면 Claude에게 알려주세요.
