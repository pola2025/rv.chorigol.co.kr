설정 체크리스트

1

Vercel 대시보드에서 도메인 추가

  1. 아래 링크를 클릭하여 Vercel 도메인 설정 페이지로 이동
  2. "Add" 버튼 클릭
  3. 도메인 입력: rv.chorigol.co.kr
  4. "Add" 버튼 클릭하여 도메인 추가
Vercel 도메인 설정 페이지 열기
2

DNS CNAME 레코드 설정

도메인 등록 업체(가비아, 카페24, 호스팅KR 등)의 DNS 관리 페이지에서 아래 레코드를 추가하세요.

타입 호스트/이름 값/대상 TTL
CNAME rv cname.vercel-dns.com 3600 또는 기본값

참고

DNS 변경 후 전파까지 최대 48시간이 소요될 수 있습니다. 보통 몇 분 ~ 몇 시간 내에 적용됩니다.

3

설정 확인

DNS 전파 후 아래 사항을 확인하세요:

  • Vercel 대시보드에서 도메인 상태가 "Valid Configuration"으로 표시
  • SSL 인증서가 자동 발급됨 (HTTPS 연결 가능)
  • https://rv.chorigol.co.kr로 접속 가능
rv.chorigol.co.kr 접속 테스트
